# FORMAE Design Studio

Create a premium, modern, bilingual (Bulgarian / English) portfolio and landing page website for an interior design and visualization brand called FORMAE by Milena.

The website should feel elegant, calm, architectural, professional, and inspiring. The overall impression should communicate trust, clarity, style, and attention to detail.

Brand Overview

Brand Name: FORMAE by Milena

Tagline / Slogan:
Design Your Life

Primary Service:
Interior design concepts, home planning, 2D layouts, 3D visualizations, and interior project development.

Core Value Proposition:
Helping clients see and understand their future home before investing in renovation, furniture, materials, and implementation.

Key Message:
See your home before you start creating it.
